# 🛒 Amazon Clone

A responsive Amazon homepage clone built using **HTML5** and **CSS3**. This project recreates the look and feel of Amazon's landing page with a clean layout and responsive design.

## 🔗 Live Demo

🌐 https://anubhav-1921.github.io/Amazon-Clone/

---

## ✨ Features

- Responsive Amazon-inspired UI
- Navigation Bar
- Search Bar
- Hero Banner
- Product Cards
- Multiple Categories
- Clean Layout
- Mobile Friendly Design

---

## 🛠️ Built With

- HTML5
- CSS3
